# TypeScript Starter Repository

This repository is a comprehensive TypeScript starter template designed for building JavaScript/TypeScript libraries and projects. It provides a professional development setup with modern tooling and best practices.

## Key Features

- **CLI Tool**: Interactive project generator (`npx typescript-starter`) for quickly setting up new projects
- **Dual Build System**: Outputs both CommonJS (`main`) and ES6 modules (`module`) for maximum compatibility
- **TypeScript Support**: Full TypeScript configuration with strict and flexible options
- **Testing Framework**: AVA for fast, concurrent unit testing
- **Code Quality**: ESLint + Prettier for consistent code formatting and linting
- **Coverage Reports**: NYC for source-mapped test coverage analysis
- **Documentation**: TypeDoc for automatic API documentation generation
- **CI/CD Ready**: Pre-configured for Travis CI, CircleCI, and AppVeyor
- **Release Management**: Standard-version for automated changelog and versioning

## Project Structure

- `src/`: Source code and tests
- `bin/`: CLI executable
- `build/`: Compiled outputs (main and module)
- `docs/`: Documentation (including this file)

## Getting Started

Run `npx typescript-starter` to use the interactive CLI generator, or clone this repo to contribute to the starter template itself.

This template emphasizes modern JavaScript development practices, tree-shaking support, and developer experience with comprehensive tooling out of the box.
